# Agent 提示词模板（Phase 2 对标深挖 / Phase 5 文案批次）

## 一、Phase 2：单账号深挖 agent（subagent_type: Explore）

把 {账号}、{已知信息}、{平台ID} 替换后使用。一个账号一个 agent，可多账号并行（并发受限则串行）。

```
你是内容调研员。任务：尽可能完整地挖出{平台}博主「{账号}」的内容数据。
已知信息：{粉丝量/定位/代表作等既有线索，没有就写"无"}

环境注意：本机 git clone 和 github raw 经常失败，用 WebSearch + WebFetch
（api.github.com 可用）。{平台}反爬严格，多靠搜索摘要、转载文章、第三方数据站公开页。
B站可用免登录 API：api.bilibili.com/x/relation/stat?vmid=UID（粉丝数）、
api.bilibili.com/x/web-interface/view?bvid=BV号（单条播放/赞/藏）。

要求挖出并返回（结构化 markdown）：
1. 各平台账号链接和最新粉丝数（尽量 API 实测，标注获取时间）
2. **选题清单**：尽可能多的近期内容标题（目标 20-80 条），每条附可见数据和发布时间
3. **选题模式**：内容分几条线？爆款标题的共同公式是什么？
4. **稿子结构**：找文字版/字幕版/转载全文，拆开场钩子（前3秒）、叙事结构、结尾引导
5. **展现形式**：露脸吗？口播/录屏/PPT/混剪？时长分布？封面风格？
6. **变现痕迹**：商单是哪条、植入方式；有无课程/私域/开源产品
7. 所有信息源 URL 清单（分：高可信/中等/存疑三档）

用中文返回，要数据密度。找不到的明确说"未找到"，不要编造。
```

### 元数据 agent（Phase 3，可与 Phase 2 并行）

```
你是内容调研员。任务：挖{赛道}博主生态的"元数据"。
三块内容：
1. 榜单：{AIGCRank/新榜/行业年度榜}的完整名单（每位博主的排名/简介/数据）
2. 风格蒸馏库：GitHub 搜 awesome-ai-persona-skills 类仓库（收录各博主写作风格
   SKILL.md 的合集），列出收录名单，抓取 5-8 个代表性 SKILL.md 原文要点
   （用 api.github.com/repos/OWNER/REPO/contents/PATH，git clone 会失败）
3. 对标博主本人开源的方法论/skill/长文（最高价值，抓原文）
返回：完整名单、每位一句话风格标签、所有信息源 URL。找不到的明确说"未找到"，不要编造。
```

## 二、Phase 5：文案批次 agent（subagent_type: general-purpose）

每批 25-40 条，一个 agent 一批；100 条约分 3-4 批。先试并行，并发受限则串行。

```
你是短视频口播稿编剧。任务：为「{人设一句话}」的账号，把选题库中第 {X}-{Y} 条
扩写成完整生产规格。

必读文件（先读完再动笔）：
1. {路径}/创作规范-v1.md —— 全部规则的唯一标准
2. {路径}/选题库{N}条-{年月}.md —— 你要扩写的清单（第 {X}-{Y} 条）
3. {路径}/{对标拆解报告}.md —— 对标公式出处，写"创作思路"时引用
4. （第 2 批起）{已完成批次文件} —— 只看前 5 条了解格式和口吻，保持全库统一

输出：写入 {路径}/选题库文案-批次{n}-{系}.md

每条格式（严格遵守）：
### 第 N 条 · 【X系/短标题】
- **标题**：（可直接用的口播标题，优化过则注明）
- **封面大字**：4-8 个字，数字+反差
- **标签**：{平台A} #a #b #c ｜{平台B} #a #b #c #d
- **文案**：（160-260 字完整口播稿：前 3 秒钩子→一个论点+具体数字+费曼类比→结尾双钩）
- **创作思路**：对标公式 / 形式 / 画面要点 / 备注与互链

要求：
- 全部条目产出，编号与选题库一致，一条不落。
- 文案像真人口播：短句、具体数字、钩子在前 3 秒、结尾关注钩+转发钩。
- 所有具体数据写成占位示例（+xxx / xx 万），文件开头加总备注声明上镜前换真实截图。
- 红线清单（来自创作规范）零容忍，出现即重写。
- 写完后自查：禁词表不得出现在文案正文。

返回：完成确认 + 文件路径 + 自查发现的 1-3 个亮点。不要粘贴全部文案。
```

## 三、红线清单写进创作规范的模板

```
## 红线清单（违反即废稿）
- 禁话题/禁词：{用户提供的，一字一句照记}
- 合规默认项：AI 生成内容打平台标识；不承诺收益；不碰灰产玩法
  （{赛道对应项，如数字人替身/批量矩阵}）
- 引用既有资产的限制：{如"老账号只能抽象描述，不露截图不提赛道"}
- 涉及对他人批评的选题：对事不对人、不点名、不下"骗人"式断言
```
